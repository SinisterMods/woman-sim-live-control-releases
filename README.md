# Woman Sim Live Control – downloads

TikTok LIVE gift effects for **Woman Simulator**: viewers' gifts add chores, mess with money and mood,
flip gravity, end the day early – or send Shrek home as your husband.

## Get it
1. Download **WomanSimLiveControl.exe** from the [latest release](../../releases/latest).
2. Put it in its own folder and open it. (Windows may warn about an unknown publisher – choose *More info → Run anyway*.)
3. In **Mod setup**, press **Install mod**, then start the game from Steam.
4. Enter your TikTok username and press **Connect LIVE**.

The panel checks for updates every time it opens and shows its version in the bottom left. When a newer
version is out you'll get a notice and an **Update** button next to the version number – click it and the
panel closes and reopens on the new version.

Press **Remove mod** in the panel to undo the game changes.
